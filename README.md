## Sobre o repositório

Este repositório funciona como um **registro contínuo da minha jornada de aprendizado em programação**.

Aqui organizo conteúdos desenvolvidos durante meus estudos, desde os primeiros exercícios de lógica de programação até práticas com desenvolvimento Web, JavaScript, PHP e Laravel.

O conteúdo inclui:

* Exercícios desenvolvidos durante cursos;
* Anotações e exemplos de implementação;
* Testes e experimentações com código;
* Práticas para fixação de novos conceitos;
* Projetos desenvolvidos durante os estudos;
* Revisões de conteúdos já estudados.

A proposta é preservar não apenas os resultados finais, mas também o **processo de aprendizado**, permitindo acompanhar como meus conhecimentos e minha forma de programar evoluem ao longo do tempo.

## Evolução dos estudos

**Início dos estudos em programação:** Setembro de 2024

Minha jornada começou com os fundamentos de **lógica de programação**, buscando desenvolver uma base sólida de raciocínio antes de avançar para tecnologias específicas.

Em seguida, comecei meus estudos em desenvolvimento Front-End com **HTML e CSS**, passando por conceitos como:

* Estruturação semântica;
* Estilização de interfaces;
* Flexbox;
* CSS Grid;
* Responsividade.

Posteriormente, avancei para **JavaScript**, adicionando comportamentos e interatividade às páginas.

Com a evolução dos estudos e o contato com desenvolvimento de aplicações Web, também passei a estudar **PHP e Laravel**, ampliando meus conhecimentos para além do Front-End e começando a compreender melhor o desenvolvimento Back-End.

Durante esse processo, os estudos passaram gradualmente de exercícios isolados para páginas mais estruturadas e, posteriormente, para **projetos que combinam diferentes conhecimentos em uma única aplicação**.

Por isso, este repositório também funciona como uma linha do tempo prática: códigos mais antigos permanecem registrados para que seja possível observar a evolução da minha organização, lógica e domínio das tecnologias ao longo do tempo.

## Objetivo a longo prazo

A intenção é manter este repositório em constante atualização conforme avanço na minha formação e aprofundo meus conhecimentos em desenvolvimento de software.

Mais do que armazenar exercícios, quero que este espaço funcione como um **histórico público de aprendizado**, permitindo:

* Registrar novos conhecimentos;
* Revisitar conteúdos importantes;
* Comparar códigos antigos com implementações mais recentes;
* Documentar projetos desenvolvidos durante os estudos;
* Acompanhar minha evolução técnica;
* Construir uma base sólida para projetos cada vez mais completos.

O objetivo não é apagar os códigos mais simples conforme evoluo, mas utilizá-los como parte do registro da minha trajetória como desenvolvedor.
